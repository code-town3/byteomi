# Byteomi

Modern web geliştirme ve UI/UX laboratuvarı.

Bu repo, [byteomi.com](https://byteomi.com) sitesinin tüm kaynak kodlarını, interaktif eğitim içeriklerini ve mühendislik simülasyonlarını barındırmaktadır. Front-end deneylerinin ötesinde, karmaşık sistemleri görselleştiren ve etkileşimli hale getiren bir teknoloji havuzudur.

## 🌟 İçerik Kategorileri (Bu Repoda Neler Var?)

Bu repo sadece bir web sitesi değil, aynı zamanda çok disiplinli bir mühendislik ve tasarım laboratuvarıdır:

- **🧠 Algoritmalar (Algorithms):** Veri yapıları, derin algoritmalar (Skip List, Wavelet Tree, FFT), uygulamalı bilimler (RANSAC, Kalman Filtresi) ve özgün laboratuvar deneyleri (XiSort, Singularity RNG).
- **⚙️ Sistemler & Simülasyonlar (Systems & Simulations):** 6 ana kategoride 100+ interaktif simülasyon:
  - **Mimari:** Yapısal yük, deprem, köprü gerilmesi, rüzgar, akustik, termal yalıtım, asansör kontrolü.
  - **Biyolojik:** Hücre döngüsü, enzim kinetiği, nöron aksiyon potansiyeli, kalp ritmi, bağışıklık yanıtı, SIR enfeksiyon modeli.
  - **Elektrik:** AC sinüs dalgası, RC devre, PWM motor kontrolü, mantık kapıları, flip-flop bellek.
  - **Finansal:** Bileşik faiz, borsa emir defteri, kripto madencilik, dinamik fiyatlandırma, sigorta risk modeli.
  - **Mekanik:** Dişli oranları, süspansiyon, PID kontrol, robot kol kinematiği, hidrolik basınç, çarpışma.
  - **Fizik:** Yerçekimi, eğik atış, sarkaç, yörünge mekaniği, akışkan dinamiği, kara delik, kuantum süperpozisyon, kaos teorisi.
- **🎨 UI LAB:** Tier 1'den Tier 12'ye kadar 100+ UI bileşeni ve tasarım deseni:
  - **Core UI:** Butonlar, Inputlar, Kartlar, Navigasyon, Rozetler.
  - **Veri & Dashboard:** Sparkline, Bar karşılaştırma, Veri gridi, Lider tablosu, Gelir kartları.
  - **Geri Bildirim & Overlay:** Boş durum, Progress bar, Doğrulama, Banner, Modal, Güvenlik overlay.
  - **Gelişmiş UI:** E-Ticaret, Giriş/Ekranlar (Auth), Mobil UI (Bottom Nav, Drawer), AI Bileşenleri (Chat, Prompt, Stream).
  - **Geliştirici & Sistem:** Terminal paneli, Kod snippet, API Builder, ECS Inspector, Render Pipeline, Network Graph.
  - **Deneysel:** Glass Panel, Neumorphism, Cyberpunk, Scroll Reveal, hareket efektleri.
  - **Anatomi & Patternler:** SaaS Landing, E-Commerce Storefront, Dashboard Shell, Mega Menu, Pricing Table, Command Bar.
- **📚 Papers (Kavram Serileri):** Bilgisayar Mimarisi, Tarayıcı Mimarisi, JavaScript Motoru, GPU Pipeline ve Ağ Sistemleri üzerine derinlemesine görsel rehberler.
